## 1. Промпты трёх уровней

`app/prompts/{beginner,club,gm}.txt` — на основе SPEC §6, но строже.
Общие жёсткие правила (у всех трёх):

1. использовать **только** ходы/оценки/мотивы из пакета фактов;
2. SAN **без Markdown**: `e4`, а не `**e4**`/`e4`/`*Nf3*`;
3. не менять оценки (`+120 cp` → «+1.2»/«+120», не «выиграно»);
4. варианты — только из PV пакета, не длиннее;
5. если факта нет — не утверждать;
6. язык русский, объём фиксирован (150–250 / 200–350 / 250–450 слов);
7. структура: общая картина → ключевые моменты → вывод.

Различия уровней — в стиле и глубине: новичку объясняются принципы и
термины в скобках; клубному — альтернативы и переломные моменты;
гроссмейстеру — сдержанный профессиональный разбор без «воды».

Загрузчик `app/prompts/__init__.py`:

```python
load_system_prompt(level) -> str     # lru_cache, InvalidLevelError
```

Файлы, а не строки в коде: промпты версионируются и ревьюятся отдельно
(RULES §8.1).

## 2. Пакет фактов

`build_fact_package(game, analyses, level) -> str` в `app/llm/prompts.py`.

Состав:

1. **Метаданные**: белые/чёрные, событие, дата, результат, ECO, число
   ходов, уровень.
2. **Все ходы партии** в SAN (`1. d4 Nf6 2. c4 …`) — чтобы модель не
   «вспоминала» партию по памяти.
3. **Ключевые моменты** — до `MAX_KEY_MOMENTS = 10`:
   * отбор: `classification ∈ {blunder, mistake, inaccuracy}` **или** мотив
     важности ≥ `KEY_MOTIF_IMPORTANCE = 4`;
   * сортировка по `delta_cp`, затем по важности мотива;
   * если ошибок нет — берутся самые «острые» ходы по дельте;
   * для каждого: полуход и номер хода, сторона, оценка после хода **за
     белых** (или «мат в N»), лучший ход и потеря, класс, рекомендация
     Policy для уровня, PV до 8 ходов в SAN, мотивы с важностью.
4. Финальная фраза-напоминание: не добавлять факты, которых нет.

Почему текст, а не JSON: модель-инструкция лучше держит структуру
конспекта; JSON провоцирует «продолжение схемы» и лишние поля. Формат
покрыт тестами (метаданные, лимит 10, отсутствие `**`, PV, мотивы).

## 3. Пример (фрагмент реального пакета)

```
# Партия
Белые: Gukesh, D.
Чёрные: Keymer, Vincent
Событие: 6th Prague Masters 2024
Результат: 1-0
ECO: E21
Ходов: 27 (53 полуходов)
Уровень объяснения: club

# Ходы партии (SAN)
1. d4 Nf6 2. c4 e6 3. Nc3 Bb4 …

# Ключевые моменты (до 10, по убыванию потери)
## 1. Полуход 46 (23...), чёрные: Rxc4
- Оценка после хода: +1.08 (+108 cp) за белых
- Лучший ход движка: Kg7; потеря 120 cp; класс: mistake
- Рекомендация для club: Kg7
- PV (до 8 ходов): Kg7 Rxc4 …
- Мотивы:
  - [4] weak_square: Слабое поле b3 рядом с королём белых …
```
