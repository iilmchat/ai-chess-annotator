# ASSISTANT_LEVELS — три уровня ассистента

Уровень — это не «сложность слов», а набор решений: глубина Stockfish,
модель LLM, рекомендация Policy, стиль промпта и использование RAG.

## Сводная таблица

| Параметр | Новичок (`beginner`) | Клуб (`club`) | Гроссмейстер (`gm`) |
| :--- | :--- | :--- | :--- |
| Движок | depth 12, MultiPV 1, ~0.2 с/ход | depth 18, MultiPV 3, ~1 с/ход | depth 28+ / 5 с, MultiPV 5 |
| LLM | LM Studio `qwen/qwen3-4b-2507` | та же локальная | DeepSeek `deepseek-chat` |
| Провайдер | локально (приватно) | локально (приватно) | облако (по умолчанию) |
| RAG | не нужен | не подмешивается | аннотации похожих позиций |
| Policy | «не зевок + принцип» | top-3 + мотивы | top-line + стратегия |
| Стиль | простой язык, принципы | тактика + стратегия | профессионально, нюансы |
| Объём | короче, 200–350 слов | 200–350 слов | 200–350 слов |

## Новичок

- **Кому:** только учится, знает правила и базовые принципы.
- **Что важно:** безопасность короля, развитие фигур, контроль центра,
  типичные ошибки; без сложной терминологии.
- **Policy:** отбрасывает ранний вывод ферзя и «зевки»; разрешает жертву,
  если она ведёт к мату (KI-020 закрыт).
- **LLM:** локальная, поэтому партия не уходит в облако.
- **Ограничение:** фильтр «зевков» — эвристика без SEE; сложные жертвы
  может недооценить.

## Клубный игрок

- **Кому:** рейтинг ~1800–2200, хочет понимать альтернативы.
- **Что важно:** почему ход хорош/плох, какой был план, что было лучше,
  как связаны тактика и структура.
- **Policy:** top-3 линии, альтернатива при разнице < 20 cp; мотивы хода.
- **LLM:** локальная средняя; приватность сохраняется.
- **Ограничение:** локальная модель ~9 ток/с — комментарий может занять
  до минуты (KI-024).

## Гроссмейстер

- **Кому:** сильный игрок, нужен профессиональный разбор.
- **Что важно:** тонкие нюансы, стратегические планы, исторический
  контекст варианта, критические переломы.
- **Policy:** top-line движка + стратегическая рекомендация.
- **RAG:** в пакет фактов добавляются аннотации похожих позиций из
  `annotated_games` (T-017); retrieval — по FEN.
- **LLM:** DeepSeek — сильнее локальной, но партия уходит в облако;
  on-prem профиль — T-105.
- **Ограничение:** RAG-эмбеддинги — хеш-заглушка (KI-025); семантика
  появится после подключения bge-m3.

## Как выбрать

| Задача | Уровень |
| :--- | :--- |
| Объяснить ребёнку, почему нельзя зевать ферзя | `beginner` |
| Разобрать свою партию до 2000 | `club` |
| Подготовить глубокий разбор для турнира | `gm` |

Уровень задаётся при анализе (`POST /v1/analyze`) и при генерации
(`POST /v1/commentary`, `POST /v1/chat`). Анализ и комментарий можно
сделать на разных уровнях: например, быстрый анализ `beginner`, а текст —
`gm`.
