## 1. Контракт

```python
choose_recommended_move(
    multipv: list[EngineLine] | tuple[EngineLine, ...],
    level: str,
    *,
    fen: str | None = None,
) -> EngineLine
```

`fen` необязателен — но только с ним работают принципы новичка. Без FEN
`beginner` деградирует до топ-1 (явно, а не «угадыванием»).

## 2. Правила по уровням

### gm

`multipv[0]` без оговорок. Гроссмейстеру нужна точность, а не
«альтернатива ради альтернативы».

### club

`multipv[0]`, но если разница оценок первой и второй линии **< 20 cp**,
возвращается вторая — «почти равная альтернатива», которую полезно
увидеть клубному игроку (SPEC §2.5). Ровно 20 cp — уже не альтернатива
(тест на границу). Мат сравнивается с сантипешками через
`±(10000 − 100·N)`, поэтому матовая линия никогда не «равна» обычной.

### beginner

1. Берём top-3.
2. Отбрасываем **ранний ферзь** (`fullmove ≤ 3` и развито < 2 лёгких фигур).
3. Отбрасываем ходы, после которых наша фигура (не пешка, не король)
   атакована и не защищена — «зевок».
4. Из оставшихся предпочитаем ход, соответствующий принципам: рокировка,
   развитие лёгкой фигуры с последней горизонтали, пешечный ход в центр
   (d4/e4/d5/e5).
5. Если принципам не соответствует ни один, берём первый приемлемый.
6. Если все три «плохие» — возвращаем `multipv[0]` (безопасный откат).

## 3. Демонстрация (из тестов)

Позиция после 1.e4 e5, «движок» советует `2.Qh5`:

| Уровень | Выбор | Почему |
| :--- | :--- | :--- |
| `gm` | `d1h5` (Qh5) | топ-1 |
| `club` | `f1c4` (Bc4) | разница 5 cp < 20 → альтернатива |
| `beginner` | `f1c4` (Bc4) | Qh5 — ранний ферзь; Bc4 — развитие |

Позиция после 1.e4 e5 2.Nf3 Nc6, «движок» советует `Nxe5` (теряет коня):

| Уровень | Выбор |
| :--- | :--- |
| `gm` | `f3e5` (Nxe5) — топ-1 |
| `beginner` | `f1c4` (Bc4) — Nxe5 оставляет коня под боем |

## 4. Почему `fen` — keyword-only и необязательный

* Обязательный FEN сломал бы сигнатуру из постановки и усложнил бы
  использование там, где позиция не нужна (`club`, `gm`);
* полностью убирать принципы «новичка» нельзя — это ключевая часть
  SPEC §2.5;
* компромисс: параметр есть, но поведение без него документировано и
  покрыто тестом (`test_beginner_without_fen_returns_top_move`).

## 5. Ограничения (KI-020)

Фильтр «бьют и не защищают» не понимает жертв: `Bxf7+` с матом в 2 хода
может быть отброшен как зевок, если слон остаётся под боем. Плановое
решение — разрешать ходы, у которых `multipv[i].mate > 0`, и добавить
простой SEE. Пока политика применяется только к top-3, а при полном
отсутствии приемлемых — откатывается на топ-1.
